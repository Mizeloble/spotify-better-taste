# notify/ 규약

- **`send()` 는 절대 예외를 올리지 않는다.** 알림이 수집을 멈추면 안 된다.
  구현체가 자기 예외를 삼키고 로그만 남긴다. 호출부는 반환값을 무시해도 된다.
- **쿨다운은 종류별이다.** 파일 하나로 합치지 말 것 — heartbeat 알림 한 번이
  스키마 변경 알림을 삼키면, 서로 다른 사고가 같은 침묵으로 덮인다.
- **새 알림 종류는 `AlertKind` 에 상수로 추가한다.** 문자열 리터럴을 직접 넘기면
  오타 하나로 쿨다운이 영원히 안 걸리는 조용한 버그가 된다.
- **봇 토큰이 URL 에 들어간다.** 예외 메시지나 로그에 URL 을 넣지 말 것.
  `resp.raise_for_status()` 금지 — 그 예외 문자열에 토큰이 담긴다.
  상태 코드만 보고 직접 처리한다.
- 채널 선택은 `build_notifier()` 한 곳에서만. 호출부가 `has_telegram` 을 직접
  묻지 않는다.
