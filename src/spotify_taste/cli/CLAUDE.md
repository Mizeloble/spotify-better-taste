# cli/ 규약

- **종료 코드가 인터페이스다.** launchd 래퍼와 셸이 게이트로 쓴다.
  정상 0, 문제 1, 재인증 필요 3.
- **파괴적 동작은 dry-run 이 기본값이다.** `classify run`, `sessions rebuild`,
  `db prune` 전부 `--write`/명시 옵션 없이는 아무것도 바꾸지 않는다.
- **진단 명령은 네트워크를 쓰지 않는다.** `auth status`, `ops status` 가
  네트워크 장애로 실패하면 정작 알고 싶은 로컬 상태도 못 본다.
  실시간 확인이 필요한 것은 `ops preflight` 하나로 모은다.
- **막힌 것은 한 번에 전부 보여 준다.** 하나 고치면 다음 것이 나오는 방식은
  사람을 지치게 한다 (`preflight` 참조).
- 시크릿을 출력하지 않는다. 토큰은 마스킹하거나 아예 찍지 않는다.
- 표시 시각만 KST 로 바꾼다. 저장은 언제나 UTC epoch ms.
