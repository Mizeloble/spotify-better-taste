# metadata/ 규약

- **복수 조회는 없다.** `GET /tracks`, `/artists`, `/albums` 는 2026-02 에
  사라졌다. 1엔티티=1콜이므로 루프에서 그냥 때리지 말 것.
- **항상 예산제로 돈다.** `--max-calls` 를 정확히 지키고 남은 것은 다음
  실행에 넘긴다. 상태는 `fetch_status` 컬럼에 있으므로 중간에 죽어도
  잃는 것이 없다.
- **재생 횟수 내림차순.** 콜드 스타트가 수만 콜이라 순서가 곧 체감 속도다.
- **404 는 `not_found` 로 못 박고 다시 묻지 않는다.** 일시적 오류(`error`)만
  다음 회차에 재시도한다.
- 트랙 응답이 아티스트·앨범 URI 를 알려 주므로 그것들이 다시 큐가 된다.
  복수 조회가 없는 세계에서 큐를 이어 가는 방법이다.
- **순서는 아티스트 → 트랙 → 앨범** (`KIND_ORDER`). 트랙이 먼저였을 때
  8천 건짜리 트랙 큐가 예산을 전부 먹어 아티스트가 나흘 연속 0명이었다.
  아티스트 큐는 2천 명 남짓이라 며칠이면 마르고, 그 뒤 예산은 저절로
  트랙으로 흐른다. 순서를 되돌리려면 그 근거부터 반박할 것.
