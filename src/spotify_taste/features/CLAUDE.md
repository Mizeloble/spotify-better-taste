# features/ 규약

- **`weights.py` 와 `behavior.py` 는 순수 함수다.** DB·HTTP·벽시계 금지.
  시간대도 모른다 — KST 시/요일은 `build.py` 가 SQL 로 내서 정수로 넘긴다.
  규칙을 표로 고정해 시험할 수 있어야 한다 (`sessions/machine.py` 와 같은 이유).
- **3층은 분모를 숨기지 않는다.** 모든 지표가 `sample_size` 와 함께 저장되고,
  분모가 0 인 지표는 0.0 이 아니라 **행 자체를 만들지 않는다**. "없음"과
  "0 이다"는 다른 말이다.
- **모든 파생 행에 `params_version` 이 박힌다.** 반감기·기저율이 바뀌면 점수의
  의미가 바뀐다. 버전 없이 저장된 점수는 재계산도 비교도 불가능하다.
- **기저율은 파라미터를 만들 때 한 번 굳힌다.** 매번 다시 재면 과거 점수가
  소급해 바뀐다. `feature_params.params_json` 에 값째로 들어간다.
- **완주도를 모르는 재생은 0 이 아니라 '모름'이다.** 0 은 "안 들었다"이고
  모름은 "말할 수 없다"다. 섞으면 백필이 덜 된 롱테일을 통째로 싫어함으로
  학습한다.
- **출처를 남긴다.** `completion_source` 로 실측/export/추정을 구분해야
  "실측만으로 다시 계산"이 가능하다 (규칙 3).
- export 신호(`reason_start`)와 라이브 신호(`end_reason`)를 같은 모드로
  취급하지 않는다. 접두사로 갈라 둔다 — 섞으면 임포트 경계에서 가짜
  불연속이 생긴다.
